# クイズで巡る東大本郷（Ver. 2.1）

GitHub Pagesで動作する、HTML・CSS・JavaScriptによる静的Webサイトです。
クイズの問題・正解・解説・設置場所は **仮データ** です。

## Ver. 2.1 で追加した機能

### QRコード読み取り（キーワード一覧＋解答ページ7件）

- 画面の「次のQRコードを読み取る」ボタンから、カメラの読み取り画面を開きます。
- ブラウザにカメラ許可を求め、可能なら背面カメラを使用します。
- 対応するQRコードを認識すると、該当する解答・解説ページへ自動で移動します。ページを開いた時点でキーワードが記録されます。
- **このサイトの登録済み7つのURLしか受け付けません**。外部サイトへの自動遷移を防ぎます。
- カメラの使用を拒否した場合やカメラがない場合は、QRコードを写した画像を選ぶ「写真から読み取る」も利用できます。
- 閉じる操作、画面を離れる操作、ブラウザのタブを非表示にする操作でカメラを停止します。再開には「カメラを再試行」を押します。
- カメラ映像や選択した写真をサーバーに送信しません。解析は端末内のJavaScriptで行います。

**ライブラリの読み込みについて：** QRコード解析には [jsQR v1.4.0](https://www.npmjs.com/package/jsqr)（Apache-2.0）を使用し、`cdn.jsdelivr.net` から読み込みます。そのため、初回のページ読み込み時にインターネット接続およびCDNへの接続が必要です。jsQRを読み込めない場合、対応ブラウザでは `BarcodeDetector` を代替使用します。どちらも利用できない場合はその旨を画面に表示します。jsQRのスクリプトを将来サイト内に配置する場合は、8ページの `<script src=...>` をすべて変更してください。

### キーワードをすべて集めたときの演出

- 最初に7つのキーワードがそろった後、キーワード一覧を開いた時に風船が画面下から上へ飛ぶ演出を**1回だけ**表示します。
- 完成後、キーワードカード7枚に淡いパール・金・緑・薄紫のグラデーション背景を適用します。
- カードごとにタイミングをずらし、斜め方向の光沢がゆっくり横切るCSSアニメーションを継続表示します。
- 未完成の場合は通常のカード表示で、アニメーションはしません。
- 端末側で「視差効果を減らす」などが有効な場合（`prefers-reduced-motion: reduce`）、風船を省略し、カードは静的なホログラム風表示にします。

## 公開URLと既存データについて

GitHub Pages の配置例：`https://yamada-masayuki.github.io/quiz/`

**7つの解答ページのファイル名と、既存のQRコードURLは変更していません。** 以前作成したQRコードはそのまま使えます。

保存キー：
- 既存の訪問履歴：`todai-hongo-quiz-progress-v1`（**変更なし**）
- 初回お祝い表示済みフラグ：`todai-hongo-quiz-progress-v1-celebration-seen-v1`（**新規**）

新バージョンを上書き配置しても、ブラウザに保存されている進捗データは維持されます。ブラウザ・端末間での同期はありません。

## ファイル構成

- `index.html`：一覧・収集状況・完成画面
- `qr/answer_{番号}_{ランダム4字}.html`：各QRコードの解答・解説ページ（7件）
- `js/config.js`：問題・解説・キーワード・ファイル名の設定
- `js/progress.js`：訪問履歴の自動記録
- `js/index.js`：一覧と進捗の描画、完成判定
- `js/answer.js`：各解答ページの内容・訪問記録
- **`js/qr-scanner.js`（追加）**：カメラ操作、写真からの読み取り、登録URL照合、ページ遷移
- **`js/celebration.js`（追加）**：風船アニメーションと初回実行フラグ
- `css/style.css`：共通画面、カメラUI、ホログラム・風船アニメーション
- `assets/images/`：装飾用SVG
- `QR_URL一覧.csv`：7件のQRコードURLの一覧

## GitHub Pagesへの更新手順

1. ZIPファイルを展開します。
2. **中の `index.html`、`css/`、`js/`、`qr/`、`assets/` などを、既存の GitHub Pages 公開ディレクトリに上書き配置**します（ZIPの中身を `/quiz/` の直下へ配置してください）。
3. デプロイ後、ブラウザを再読み込みします。古いCSSやJSがキャッシュされている場合は、スーパーリロードまたはサイトデータのキャッシュを消去して再確認してください（進捗を保持したい場合、サイトデータ全体を削除しないでください）。
4. iPhoneのSafari、AndroidのChromeなど、実際の端末でカメラの許可→読み取り→解放を確認してください。

## 確認項目

1. キーワード一覧の「次のQRコードを読み取る」を押すと、読み取り画面が開く。
2. カメラを許可すると背面カメラの映像が出る。
3. 7個のQRコードのどれを読み取っても該当する解答ページに移動し、自動で1文字が解放される。
4. 解答ページ内の同ボタンからも、次のQRコードを読み取れる。
5. 許可を拒否しても「写真から読み取る」は利用できる。
6. 読み取り画面を閉じるとカメラが停止する。
7. 7文字完成後の一覧ページで風船が上昇し、再読み込みでは再表示されない。
8. 完成後は7枚のカードの背景がゆっくりきらめき続ける。
9. 未完成ではカードのアニメーションが表示されない。

> ブラウザからのカメラ利用は原則HTTPSが必要です（`localhost` は開発用の例外）。`file://` で開く方式は推奨しません。カメラが使用できるかどうかは、端末・ブラウザ・許可設定に依存します。

## テスト用：進捗と風船演出の初期化

ブラウザの開発者ツールで、次のコードを実行してから再読み込みします。

```javascript
// 進捗と初回風船表示フラグの両方を消去する
localStorage.removeItem('todai-hongo-quiz-progress-v1');
localStorage.removeItem('todai-hongo-quiz-progress-v1-celebration-seen-v1');
```

すでに7文字完成していて、風船だけを再確認したいときは、2行目のフラグだけを削除して一覧ページを再読み込みしてください。
